
# PLP Python Week 4 Assignment

This assignment practices Python functions, parameters, return values, and default arguments.

## Files

- `welcome.py`: Defines a reusable function that returns a welcome message for a given name.
- `toolbox.py`: Defines functions to double a number, check whether a score is a pass, and greet a person.

## Reflection

The hardest function to write was `greet()` because it uses an optional greeting with a default value. I learned that the default greeting is used when no greeting is provided, but I can supply a different greeting when calling the function.
